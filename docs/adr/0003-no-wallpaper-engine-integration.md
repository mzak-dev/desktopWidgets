# No Wallpaper Engine integration

Wallpaper Engine exposes no API, CLI, IPC, colour query or playback-state query; its developer said so on the official forum. Its audio visualiser consumes WASAPI loopback and conflicts with other consumers, and its own mitigation is a per-application exclusion rule. Nothing is left to integrate with, so it is out of scope, recorded here so the question is not reopened.
